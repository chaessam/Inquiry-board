# 탐구보드 (inquiry-board)

개념기반탐구 수업을 위한 사고전략 활동지 도구입니다.
선생님은 활동지를 만들어 과제로 내고, 학생은 크롬북·태블릿·휴대폰에서 바로 쓰고 제출합니다.

## 1단계에 들어 있는 것

| 영역 | 내용 |
| --- | --- |
| 교실 | 가입 없이 교실 만들기, 학생용 교실 코드(6자리)와 QR, 교실 이름 + 비밀번호(숫자 4자리)로 어느 기기에서든 들어오기 (교실 이름은 서로 겹치지 않게) |
| 학생 입장 | 교실 코드(또는 QR) → 내 번호 누르기. 기기가 번호를 기억. ‘내 과제’에서 번호 바꾸기 |
| 장난 막기 | 접속 주소별 요청 횟수 제한, 비밀번호 5번 틀리면 교실 잠금(15분부터 최대 하루), 쉬운 비밀번호 거절 |
| 번호 정리 | 잘못된 번호로 낸 답을 선생님이 제출 현황에서 다른 번호로 옮기기 |
| 개인정보 | `#/privacy` 안내 페이지, 글꼴을 앱 안에 넣어 외부 요청 없음 |
| 사고전략 | 개념 획득, 프레이어 모델, 일반화 문장 만들기 |
| 과제 | 마감 정하기 → 학생 제출·다시 제출 → 번호별 제출 현황 → ‘모두 받기’로 이 기기 보관함에 저장 |
| 도움말 | 화면마다 접었다 펴는 도움말. 일반화에는 관계 동사 상자(눌러서 넣기), 수준 1→2→3 비계, 점검표 |
| 단원 | 단원 이름·개념 렌즈·핵심 개념·일반화·안내 질문, 탐구 단계(8단계) 고르기 |

## 데이터는 어디에 저장되나요

| 데이터 | 저장 위치 | 보관 기간 |
| --- | --- | --- |
| 단원, 명렬표(이름), 받아 둔 결과물 | 선생님 기기(IndexedDB) | 지울 때까지 |
| 학생이 쓰는 중인 답 | 학생 기기(IndexedDB) | ‘이 기기에서 지우기’까지 |
| 교실(코드, 학생 수) | 서버(D1) | 1년 동안 안 쓰면 삭제 |
| 과제, 제출한 답 | 서버(D1) | 마감 후 14일 지나면 자동 삭제 |

서버는 학생 이름을 모릅니다. 번호와 기기 표시만 받습니다.
선생님 비밀번호와 기기 열쇠는 서버에 해시로만 저장합니다.
요청 횟수 제한에 쓰는 접속 주소도 날마다 바뀌는 해시로만 남기고, 시간 창이 끝나면 지웁니다.

운영자 정보(이름, 문의 블로그)는 `src/content/privacy.js`에 있습니다.

## 내 컴퓨터에서 실행하기

Node.js 20 이상이 필요합니다.

```bash
npm install
```

```bash
npm run db:migrate:local
```

```bash
npm run serve
```

브라우저에서 <http://localhost:8788> 을 엽니다. 서버(API)와 화면이 함께 뜹니다.

## 배포하기 (Cloudflare Pages + D1)

1. Cloudflare에 로그인합니다. 브라우저 창이 열리면 승인하세요.

   ```bash
   npx wrangler login
   ```

2. 데이터베이스를 만듭니다. 출력된 `database_id`를 `wrangler.toml`의 `database_id`에 붙여 넣으세요.

   ```bash
   npx wrangler d1 create inquiry-board
   ```

3. 서버 데이터베이스에 표를 만듭니다.

   ```bash
   npm run db:migrate:remote
   ```

4. Pages 프로젝트를 만들고 배포합니다. 처음 한 번만 프로젝트를 만들면 됩니다.
   배포 뒤 해시에 섞을 비밀값 두 개(`PIN_PEPPER`, `RATE_SALT`)를 아무 긴 글자로 정해 넣어 두면 더 안전합니다.
   (`npx wrangler pages secret put PIN_PEPPER`) 단, `PIN_PEPPER`를 나중에 바꾸면 기존 교실 비밀번호가 맞지 않게 되니 처음 한 번만 정하세요.

   ```bash
   npx wrangler pages project create inquiry-board --production-branch main
   ```

   ```bash
   npm run deploy
   ```

배포가 끝나면 `https://inquiry-board.pages.dev` 같은 주소가 나옵니다.
요청 수는 Workers 유료 요금제(월 5달러)의 계정 한도를 다른 서비스와 함께 씁니다.

## 폴더 구성

| 경로 | 설명 |
| --- | --- |
| `functions/api/[[path]].js` | 서버 우편함 API (교실, 과제, 제출, 자동 삭제) |
| `migrations/` | D1 데이터베이스 표 |
| `src/strategies/` | 사고전략별 준비 화면, 학생 활동지, 교사용 보기 |
| `src/content/guides.js` | 도움말 문구 (탐구 단계 설명, 일반화 동사·예시·점검표) |
| `src/screens/teacher/` | 교사 화면 (홈, 교실, 활동지 만들기, 제출 현황, 보관함) |
| `src/screens/student/` | 학생 화면 (들어오기, 내 과제, 활동지) |
| `src/lib/db.js` | 기기 저장소 (IndexedDB) |

## 알아 두기

- 일반화 도움말은 Erickson의 일반화 비계(수준 1 → ‘어떻게? 왜?’ → 수준 2 → ‘그래서?’ → 수준 3)를 바탕으로, 동사 목록과 예시는 초등 수업에 맞게 다시 썼습니다.
- 글꼴은 Google Fonts의 Gothic A1과 Jua를 씁니다.
